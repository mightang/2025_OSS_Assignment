# Turtle Runaway Game

## 1. 개요
Turtle Runaway Game은 Python의 `turtle` 모듈과 `tkinter` GUI를 활용하여 구현한 간단한 추격 게임이다.  
플레이어가 조작하는 **추격자 거북이(red)**와 자동으로 움직이는 도망자 거북이(blue)가 등장하며, 제한 시간 내에 도망자를 잡는 것이 목표이다.

## 2. 조작 방법
- ↑ (Up Arrow) : 앞으로 이동  
- ↓ (Down Arrow) : 뒤로 이동  
- ← (Left Arrow) : 왼쪽 회전  
- → (Right Arrow) : 오른쪽 회전  
- P : 게임 일시정지/해제  
- R : 게임 재시작  

## 3. 게임 규칙
- 제한 시간은 60초이다.
- 도망자(blue)는 무작위 속도 변화를 가지며 벽에 부딪히면 반사된다.
- 추격자(red)는 플레이어가 직접 조종한다.
- 두 거북이의 거리가 일정 범위(`catch_radius`) 이내가 되면 도망자가 잡히며 게임이 종료된다.
- 제한 시간 내에 잡지 못할 경우 게임은 실패(FAILED)로 종료된다.

## 4. 점수 계산
- 점수 = 60초 - 포획까지 걸린 시간  
- 제한 시간 내 포획 실패 시 점수는 0점이다.
- 최단 포획 기록(Best Time)을 저장 및 갱신한다.

## 5. 코드 구성
- EscapeMover : 도망자 거북이 클래스 (자동 AI, 무작위 속도 + 벽 반사)
- ManualMover : 추격자 거북이 클래스 (사용자 조작, 키보드 입력 처리)
- RunawayGame : 게임 진행 관리 (UI 표시, HUD, 시간/점수 관리, 게임 상태 제어)
